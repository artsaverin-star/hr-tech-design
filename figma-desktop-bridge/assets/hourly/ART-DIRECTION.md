# Bulochka hourly art direction

These scenes are original Bulochka assets for the compact Figma plugin. They use a quiet, tactile 3D object language: the interface stays neutral while the character, glass and light carry the color.

## Shared generation prompt

```text
Use case: illustration-story
Asset type: wide hourly hero scene for a compact Figma plugin
Subject: one round golden brioche character with realistic glossy crust, one diagonal baked score, tiny charcoal eyes, a tiny warm smile and short simple arms
Style: premium tactile photorealistic 3D editorial object illustration; transparent liquid-glass orb; subtle cyan, apricot and lilac refractions; seamless light studio environment
Composition: wide panoramic; orb and character on the right 55%; calm negative space on the left for UI copy; crop-safe edges; no rectangular frame
Constraints: preserve the same character identity and a clear small-size silhouette; no text, letters, logos, watermark, embedded UI, pixel art or border
```

The 07:00 image is the character and material reference for the other scenes.

## Delivery format

- Runtime asset: `688×260` WebP.

- Each scene must remain below 64 KiB for offline embedding.
