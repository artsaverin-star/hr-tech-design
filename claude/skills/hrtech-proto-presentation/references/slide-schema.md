# Справочник схемы `presentationSlides.ts`

Вся презентация задаётся **одним** экспортируемым объектом `PRESENTATION_CONFIG: PresentationConfig` в файле `src/presentation/presentationSlides.ts`.

```ts
export const PRESENTATION_CONFIG: PresentationConfig = {
    title: 'Название продукта',
    defaultDevice: 'desktop', // 'mobile' (375×812) или 'desktop' (1440×900)
    slides: [ /* 7 видов слайдов ниже */ ],
};
```

## Все 7 видов слайдов (копируй и подставляй свои данные)

### 1. `single` — Один живой экран
- Для `mobile`: 2 колонки (текст слева + живой телефон справа).
- Для `desktop`: центрированный текст сверху + крупное живое окно браузера снизу.

```ts
{
    id: 'goal',
    kind: 'single',
    title: 'Мои встречи в Я Team',
    body: 'Вся работа со встречами живёт там, где сотрудники уже начинают рабочий день.',
    screen: {
        query: 'stage=3&screen=home',
        // device: 'mobile' — опционально, если отличается от defaultDevice
    },
}
```

### 2. `flow` — Сценарий со стрелками из кликнутой кнопки
- Для `mobile`: **2 или 3** экрана.
- Для `desktop`: **строго 2** экрана (3 десктопа станут нечитаемыми).
- У каждого экрана, кроме последнего, **обязателен** `hotspot` — движок находит этот элемент в живом DOM iframe, обводит акцентной рамкой и тянет из него плавную стрелку к следующему экрану.

```ts
{
    id: 'prep-flow',
    kind: 'flow',
    title: 'Подготовка к встрече за две секунды',
    body: 'Открываем сводку прямо из расписания и видим прошлые договорённости и открытые вопросы.',
    screens: [
        {
            query: 'stage=3&screen=home',
            hotspot: {
                text: 'Подготовиться',
                // aria: '...',    // удобно для иконочных кнопок и табов без текста
                // selector: '...', // опционально сужает поиск CSS-селектором
                // nth: 0,         // номер совпадения с 0, если кнопок с таким текстом несколько
                // maxBottom: 720, // обрезает рамку сверху таб-бара для высоких карточек
            },
        },
        {
            query: 'stage=3&screen=home&drawer=prep',
            // targetY: 260, // опционально: куда в пикселях исходного viewport входит стрелка
        },
    ],
}
```

### 3. `compare` — Сравнение рядом (До/После, Этапы, Десктоп + Мобилка)
- Можно ставить `caption` под каждым экраном.
- `arrows`: по умолчанию `true` (прямые стрелки слева направо); поставь `arrows: false`, если показываешь независимые варианты (например, Десктоп и Мобилка).

```ts
{
    id: 'desktop-vs-mobile',
    kind: 'compare',
    title: 'Одинаково удобно на компьютере и в телефоне',
    body: 'Один сценарий без потери важных действий при переходе в дорогу.',
    arrows: false,
    screens: [
        { query: 'screen=list', device: 'desktop', caption: 'Десктоп · 1440' },
        { query: 'screen=list', device: 'mobile', caption: 'Мобилка · 375' },
    ],
}
```

### 4. `numbers` — 2–3 больших факта (ТОЛЬКО с реальными данными!)
```ts
{
    id: 'scale',
    kind: 'numbers',
    title: 'Я Team уже открывают каждый день',
    body: 'Живая привычка уже сформирована — не нужно приводить людей в новый сервис.',
    source: 'YTAPP-0000 · продуктовая аналитика Q2',
    items: [
        { value: '19 000', label: 'человек открывают приложение каждый будний день' },
        { value: '4,58', label: 'индекс удовлетворённости из 5' },
        { value: '69%', label: 'руководителей заходят каждый месяц' },
    ],
}
```

### 5. `bars` — 3–5 горизонтальных полос сравнения (ТОЛЬКО с реальными данными!)
Доступные цвета `tone`: `'indigo' | 'purple' | 'orange' | 'blue' | 'green' | 'neutral'`.

```ts
{
    id: 'top-actions',
    kind: 'bars',
    title: 'Куда люди заходят чаще всего',
    body: 'Календарь и поиск уже на первых местах — встречи органично встают рядом.',
    source: 'INTRANETPRODUKT-217 · срез событий за месяц',
    bars: [
        { label: 'Анкета сотрудника', display: '76,8%', value: 76.8, tone: 'indigo' },
        { label: 'Поиск', display: '43,6%', value: 43.6, tone: 'purple' },
        { label: 'Виджет календаря', display: '40,7%', value: 40.7, tone: 'blue' },
        { label: 'Сервисы', display: '39,5%', value: 39.5, tone: 'neutral' },
    ],
}
```

### 6. `toggleNumbers` — Переключаемые срезы цифр (ТОЛЬКО с реальными данными!)
```ts
{
    id: 'audience-split',
    kind: 'toggleNumbers',
    title: 'Как различается работа в будни и выходные',
    body: 'В будни люди заходят по несколько раз, чтобы проверить расписание и коллег.',
    ariaLabel: 'Выбор периода',
    source: 'YTAPP-0000 · отчёт по сессиям',
    groups: [
        {
            id: 'weekdays',
            label: 'Будни',
            items: [
                { value: '77,5%', label: 'всех сессий за неделю' },
                { value: '55%', label: 'начинаются с Главной' },
            ],
        },
        {
            id: 'weekends',
            label: 'Выходные',
            items: [
                { value: '22,5%', label: 'всех сессий за неделю' },
                { value: '1,2', label: 'среднее число экранов за визит' },
            ],
        },
    ],
}
```

### 7. `checklist` — Финальный итог / этапы / метрики запуска (3–6 пунктов)
```ts
{
    id: 'metrics',
    kind: 'checklist',
    title: 'Как поймём, что решение сработало',
    body: 'Четыре метрики на первые шесть недель после раскатки.',
    primaryActionLabel: 'Открыть прототип',
    primaryQuery: 'stage=3&screen=home',
    items: [
        { title: 'Открытие итогов после встречи', detail: 'Доля участников, открывших саммари в день созвона' },
        { title: 'Повторные заходы за неделю', detail: 'Возврат в «Мои встречи» не реже двух раз' },
        { title: 'Время до нужной цитаты', detail: 'Поиск ответа по встрече быстрее 15 секунд' },
    ],
}
```

## Если в прототипе НЕТ query-роутинга (только `useState`)

Не переписывай весь прототип! Используй `steps` на нужном `PresentationScreen` — движок сам откроет базовый URL внутри iframe, аккуратно прокликает нужные кнопки или заполнит поиск, снимет фокус и замерит `hotspot`:

```ts
{
    query: '',
    steps: [
        { click: 'Заявки' },
        { fill: { target: 'Поиск по фамилии', value: 'Смирнов' }, waitMs: 200 },
        { click: 'Открыть заявку', waitMs: 150 },
    ],
    hotspot: { text: 'Согласовать' },
}
```

## Как безошибочно подбирать `hotspot`

1. Всегда запускай прозвон перед заполнением `presentationSlides.ts`:
   ```bash
   node scripts/check-presentation.mjs --probe "<URL-экрана>" --device mobile
   ```
2. Копируй `text` или `aria` **дословно** из вывода прозвона.
3. Если элемент — кнопка без текста (иконка, аватар, крестик) — используй `aria`.
4. Если на экране две одинаковые кнопки (например, две кнопки «Подробнее») — укажи `nth: 0` или `nth: 1`.
5. Если карточка длинная и уходит под нижний таб-бар — добавь `maxBottom: 720` (для `mobile`) или `maxBottom: 860` (для `desktop`).
6. Если прозвон показал нестандартный тег (`div` без `role="button"`), добавь `selector: '[data-card="summary"]'` или поставь на нужный элемент в прототипе атрибут `data-hotspot="1"`.
