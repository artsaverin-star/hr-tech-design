# Карта сценариев Яндекс Тима

Снимок по исходникам: 13 ноября 2026. Основная оболочка исследована для iOS; общий KMP-код
не означает проверенное совпадение Android. Карта охватывает области приложения и известные
входы во встроенные продукты. Полный внутренний процесс каждого удалённого веб-сервиса
не объявляется проверенным: см. [покрытие](sources-and-coverage.md).

## Роли основных поверхностей

| Поверхность | Задача человека | Типичный результат | Подробности |
|---|---|---|---|
| Главная | Понять текущий день и выполнить актуальное дело | Конкретная встреча, документ, поездка, событие, сообщение | [Главная](home-search.md) |
| Календарь | Управлять временем и участием | Событие, приглашение, расписание, переговорка/конференция | [Календарь](calendar-people.md) |
| Поиск | Найти известного человека или рабочий объект | Профиль, Wiki, задача Tracker, публикация, место | [Поиск](home-search.md) |
| Этушка | Открыть корпоративную социальную поверхность | Настроенный веб-сервис Этушки и его контент | [Встроенные сервисы](services-shell.md) |
| Сервисы | Найти и открыть доступный рабочий продукт | Корень конкретного сервиса, настройки или помощь | [Каталог](services-shell.md) |
| Ссылка / push | Продолжить действие по конкретному поводу | Целевой объект, если пройдены проверки входа и маршрута | [Оболочка](services-shell.md) |

Это описательное прочтение проверенных маршрутов, не данные о частотности. Название,
иконка и место существующего продукта — часть контекста, но не основание копировать
ту же схему для любого нового сценария.

## Связи, которые легко потерять при дизайне

- Главная → событие открывает событие календаря. Это не открытие архива расшифровок.
- Поиск → профиль/объект → действие сохраняет смысл исходного запроса и путь назад.
- Каталог → продукт отвечает намерению «открыть сервис». Контекстное действие отвечает
  намерению «сделать что-то с этим объектом». Одинаковый продукт может иметь оба входа.
- Событие → проведение → материалы требует реальной связи и статусов. Отсутствие материалов
  не равно отсутствию события или отсутствию доступа.
- Материал → Марс → источник → возврат требует сохранённого ID и контекста.
  Закрытая встреча не становится доступной от одного наличия AI-кнопки.
- Нативная оболочка и веб-продукт могут иметь разные механизмы Back. Их техническое наличие
  не оправдывает два конкурирующих заголовка на одном экране.

Прежде чем менять любую из связей, прочитай конкретную справку и источник. Для критерия
размещения новой функции используй [решение о встраивании](integration.md).
