# Булочка · HR TECH DESIGN — установка для дизайнера

Булочка даёт твоему помощнику знания HR Tech и доступ к открытому Figma-файлу. Помощник — тот,
которым ты уже пользуешься: **Codex** или **Claude Code**. Задачи ты по-прежнему ставишь обычными
словами. Там же остаются история, прогресс, остановка, лимиты и настройки модели.

Сама Булочка задачи не выполняет и ничего не запускает в фоне — кнопок «сделай за меня» в ней нет.
Её интерфейс — это:

- **Умения**: что помощник умеет, когда умение включается и как попросить;
- **Настройки**: помощник, связь с Figma, личный токен, обновление умений и что показать поддержке.

У каждого дизайнера свой аккаунт помощника и свои задачи. Никакого общего аккаунта команды или
фонового сервиса настраивать не нужно.

## Установка — одна команда (~5 минут)

Вставь одну строку в Терминал на Mac и нажми Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/artsaverin-star/hr-tech-design/main/install.sh | bash
```

Команда всё поставит и подключит: помощника, связь с Figma и умения HR Tech. Проект скачается в
`~/hr-tech-design`, а папка с плагином откроется сама.

> Если Mac впервые без инструментов разработчика, установщик может попросить подтвердить Xcode
> Command Line Tools или ввести пароль Mac для Homebrew. Это нормально и нужно только один раз.

Дальше два разовых шага:

1. Войди в своего помощника: в Терминале запусти `codex` и войди через аккаунт ChatGPT. Если ты
   работаешь в Claude Code — запусти `claude` и войди как обычно.
2. В desktop Figma открой **Plugins → Development → Import plugin from manifest…** и выбери
   `~/hr-tech-design/figma-desktop-bridge/manifest.json`.

## Как работать каждый день

1. Открой нужный файл в desktop Figma и запусти **Булочку / HR TECH DESIGN**.
2. В разделе **Умения** при необходимости посмотри нужное умение и пример формулировки.
3. Открой задачу у своего помощника и попроси сделать работу обычными словами.
4. Когда помощник обратится к Figma, Булочка покажет, что связь есть; **Настройки** нужны для проверки только при проблеме.
5. Оставь Figma-файл и Булочку открытыми, пока помощник меняет макет.

Примеры:

- «Переведи выделенный экран на mobile 375 по HRDS» — `hrtech-mobile`;
- «Проверь выделенный макет на HRDS и исправь нарушения» — `hrtech-audit`;
- «Собери эти экраны в спецификацию сценария» — `hrtech-spec`;
- «Заведи из этой спеки живой прототип в Прототипнице» — `hrtech-prototipnitsa`;
- «Синхронизируй живой прототип обратно в Figma-спеку» — `hrtech-proto-spec`.

Помощник сам подберёт умение по смыслу. При необходимости его можно назвать явно, по имени.
Булочка не дублирует модель, настройки, разрешения, прогресс и остановку — всё это уже есть
у помощника.

## Что находится в Булочке

### Умения

Для каждого умения показаны назначение, примеры задач, необходимые входные данные и зависимости.
Каталог объясняет возможности; он не запускает отдельного агента и не создаёт задачу за тебя.

### Настройки

Здесь находятся:

- связь с текущим Figma-файлом и с помощником;
- личный Figma-токен;
- установленные версии умений HR Tech и обновление;
- версия движка и что показать поддержке, если что-то не так.

## Figma-токен — комментарии и библиотека (по желанию)

С личным токеном помощник может читать комментарии в макете, делать скриншоты и искать компоненты
в опубликованной библиотеке HRDS.

1. Открой figma.com → аватар → **Settings → Security → Personal access tokens**.
2. Создай токен со скоупами: *File content* — Read; *Comments* — Write; *File metadata*,
   *File versions* — Read; *Library assets*, *Team library content* — Read.
3. Вставь токен в Булочке: **Настройки** → «Доступ к комментариям» → добавить токен. Или повторно
   запусти `./setup.sh` — он тоже про токен спросит.

Токен хранится только на твоём Mac в `~/.hrtech/figma-token` с правами 600. Без токена основная
работа через desktop Figma продолжает работать.

## Если что-то не так

- Открой **Настройки** и проверь связь с Figma, помощника и версию умений.
- Проверь, что мост на месте: Codex — `codex mcp list`, Claude Code — `claude mcp list`;
  в списке должен быть `figma-hrtech`.
- Если моста или умений нет, выполни `cd ~/hr-tech-design && ./setup.sh`, затем перезапусти
  помощника.
- Если Figma не отвечает, закрой и заново открой Булочку в нужном файле.
- Если помощник не видит обновлённое умение, обнови установку и перезапусти его.

## Обновиться

В **Настройках** используй обновление умений и движка. Вручную то же самое:

```bash
cd ~/hr-tech-design && git pull && ./setup.sh
```

После обновления перезапусти помощника, а Булочку в Figma закрой и открой заново.

Обновление — единственный момент, когда новые умения подключаются к твоему помощнику: ничего в фоне
не работает и само по себе новое умение не приедет. Если коллега говорит «я добавил умение», нажми
«Обновить» в Настройках.

## Как поделиться знанием

Командные правила и умения ездят через git, но выполнение остаётся личным. Проверенный приём можно
добавить в `claude/knowledge/team-notes.md` в формате `## Имя — дата`, затем отправить изменение в
репозиторий. После обновления остальные дизайнеры получат новую версию умений.
