# Булочка 5.0 · установка и работа для дизайнера

Булочка даёт вашему помощнику (**Codex, Claude Code, Antigravity или Cursor**) доступ к открытому файлу Figma и знания HR Tech. У каждого дизайнера свой аккаунт и локальный мост на его Mac.

## Установка за 1 шаг

В плагине откройте **Настройки → Скопировать команду** (или скопируйте строку ниже), вставьте в Терминал и нажмите Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/artsaverin-star/hr-tech-design/main/install.sh | bash
```

Команда сама:
- проверит и скачает пакет Булочки со встроенным движком в `~/Library/Application Support/Bulochka`;
- найдёт все установленные у вас помощники (**Codex, Claude Code, Antigravity, Cursor**) и подключит им MCP `figma-hrtech`;
- подключит актуальные умения HR Tech.

Отдельное приложение-установщик, Git, Homebrew, sudo и системный Node.js не нужны.

После завершения:
1. Откройте **новый чат** помощника (в Claude Desktop — вкладку **Code**).
2. В Figma откройте рабочий макет и запустите **Plugins → From Yandex → Bulochka**.
3. Попросите помощника: «Подключись к Figma через Булочку и назови открытый файл. Ничего не меняй».

## Как работать каждый день

1. Откройте нужный файл в desktop Figma и запустите **Plugins → From Yandex → Bulochka**.
2. На **Главной** выберите нужный пример — клик сразу скопирует текст запроса в буфер.
3. Выделите экран в Figma и отправьте задачу в чат вашего помощника.
4. Оставьте Булочку открытой (её можно свернуть в угол кнопкой `−`, связь сохранится).
5. Если параллельно открыто несколько файлов Figma, включите в **Настройках** переключатель **«Только этот файл»** — тогда случайный клик в соседней вкладке не уведёт помощника в другой макет.

## Токен Figma (необязательно)

Для обычной работы с открытым файлом токен **не нужен**. Он понадобится только для комментариев, истории версий, поиска по опубликованным библиотекам и локального индекса `hrtech-figma-search`.

1. Откройте figma.com → аватар → **Settings → Security → Personal access tokens**.
2. Создайте токен со скоупами: *File content* — Read; *Comments* — Write; *File metadata*, *File versions* — Read; *Library assets*, *Team library content* — Read.
3. В Булочке откройте **Настройки → Токен Figma → Добавить токен**, вставьте `figd_…` и нажмите **Сохранить**. Токен сразу применится без перезапуска помощника (и хранится локально в `~/.hrtech/figma-token` с правами `600`).

## Если что-то пошло не так

- **«Нет подключения» после установки:** помощники (особенно Codex и Claude) запускают MCP только при открытии **нового чата**. Откройте новый чат и напишите любой запрос к Figma — связь поднимется сама.
- **«Открыто в другой вкладке»:** этот же файл подключён в другом окне Булочки — нажмите **«Подключить здесь»**.
- **Нужно обновить или починить:** нажмите **Настройки → Обновить / Починить**, либо повторите команду установки в Терминале (она безопасна, сохраняет токен и `team-notes.md`).
- **Если ошибка повторяется:** откройте **Настройки → Диагностика → Скопировать отчёт** и пришлите отчёт вместе с текстом ошибки из чата. Лог последней установки лежит в `~/.hrtech/install.log`.
