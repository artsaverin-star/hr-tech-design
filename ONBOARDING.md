# HR TECH DESIGN — установка для дизайнера

Мост между Figma и Claude: запускаешь плагин, открываешь `claude` в Терминале и **описываешь задачу
словами** — Claude делает её по зашитым правилам вашей ДС (мобильная версия, орфография, сборка
сценариев, приведение к HRDS, справка по компонентам).

У каждого дизайнера — **свой аккаунт Claude** (свои лимиты, своя подписка). Общего настраивать нечего.

## Установка — одна команда (~5 минут)

Вставь **одну строку** в Терминал на Mac и нажми Enter:

```
curl -fsSL https://raw.githubusercontent.com/artsaverin-star/hr-tech-design/main/install.sh | bash
```

Она сама поставит Node.js, Claude Code, скачает проект в `~/hr-tech-design`, подключит мост и команды
`/hrtech` + `/hrtech-digest` + базу знаний, и откроет в Finder папку с плагином.

> Если Mac впервые без инструментов разработчика — установщик попросит подтвердить установку
> Xcode Command Line Tools и может спросить пароль Mac (для Homebrew). Это нормально, один раз.

Дальше — **два разовых шага руками** (их командой не сделать):

1. **Войди в Claude** (свой аккаунт): в Терминале набери `claude` и залогинься.
2. **Поставь плагин в Figma:** десктопная Figma → **Plugins → Development → Import plugin from manifest…**
   → выбери `~/hr-tech-design/figma-desktop-bridge/manifest.json`.

## Как работать (каждый день)

1. Открой рабочий файл в Figma и запусти плагин **HR TECH DESIGN** (Plugins → Development).
   Мост поднимается сам — на лице виджета загорятся чипы **Мост · Связь · Вход**. Жать ничего не нужно.
2. В Терминале: `cd ~/hr-tech-design && claude` (для сложного нового экрана — `claude --model fable`).
3. Выдели нужный фрейм(ы) в Figma.
4. **Опиши задачу обычными словами.** Примеры:
   - «сделай мобильную версию выделенного экрана»
   - «исправь орфографию в этом фрейме»
   - «собери выделенные экраны в сценарий»
   - «приведи макет к компонентам HRDS»
   - «что ты знаешь про HRDS Drawer?» — справка по ДС
   - «добавь паттерн: …» — доучить систему новому типу экрана

Прогресс, аккаунт и остаток лимитов видно прямо в плагине. Прервать ответ — **Esc**.
Большой экран дроби на части. Плагин держи открытым, пока Claude работает с файлом.

## База знаний команды

Знание ездит через git, отдельных кнопок в плагине нет.

- **Забрать наработки коллег** — нажми в виджете **«Починить движок»**: он делает `git pull`
  и заново подключает команды, базу и скилы. Это же обновляет и сам движок.
- **Поделиться приёмом** — допиши свою секцию в `claude/knowledge/team-notes.md`
  (формат: `## Имя — дата`, дальше текст) и запушь. У остальных появится после «Починить движок».
  Формулировки причешут позже — пиши как есть.

Ничего настраивать для этого не нужно: ни `gh auth login`, ни доступа в Collaborators.

## Figma-токен — комментарии и REST (один раз, по желанию)

С личным токеном Булочка умеет больше: читать **комментарии** из файла (треды редакторов и
ревьюеров), делать скрины через API и искать компоненты по опубликованной библиотеке HRDS.

1. **Создай токен:** figma.com → аватар → **Settings** → вкладка **Security** →
   **Personal access tokens** → Generate new token. Скоупы: *File content* — Read;
   *Comments* — Write; *File metadata*, *File versions* — Read; *Library assets*,
   *Team library content* — Read. Скопируй токен `figd_…` — он показывается один раз.
2. **Отдай его Булочке** одним из двух способов:
   - в виджете нажми **шестерёнку** → поле токена → вставь и сохрани;
   - или запусти `./setup.sh` — он спросит про токен, сам откроет страницу создания
     и попросит вставить. (Шаг 1 тогда можно не делать вручную.)

   Токен ляжет в `~/.hrtech/figma-token` (права 600). Пропустил — не страшно, добавишь потом
   любым из двух способов.

Токен сохраняется только на твоём маке (`~/.hrtech/figma-token`). Он личный — комментарии
будут от твоего имени, никому его не передавай. Без токена всё остальное работает как раньше.

### Помощник работает сам

Установщик уже поставил фонового помощника в автозапуск: он стартует при входе в систему,
держит мост живым и сам подключает свежие знания. Вручную запускать ничего не нужно.

Остановить: `launchctl unload ~/Library/LaunchAgents/design.hrtech.bulochka.runner.plist`.
Запустить обратно — `load` вместо `unload`.

## Если что-то не так

- **Оранжевый баннер «Починить движок»** — жми его первым делом. Он подтягивает свежую версию
  и перезапускает помощника; лечит большинство проблем.
- **Не подключается** — на лице виджета три чипа: **Мост · Связь · Вход**. По ним видно,
  на каком шаге встало. Кнопка «Подключить» появляется, только если связь отвалилась —
  в обычной жизни жать её не нужно, мост поднимается сам.
- **«No MCP server found» / «нет инструмента figma_execute»** — закрой все сессии `claude` и запусти
  одну заново (сессия была запущена раньше установки). Ещё вариант — в чате `/mcp` →
  `figma-hrtech` → Reconnect.
- **Плагин завис** — закрой и открой заново. Плагин должен быть открыт всё время работы.

## Что в виджете под шестерёнкой

**Настройки** — там же, где Figma-токен: список **«Что умеет»** — какие скилы подключены и какими
словами их звать. Скилы срабатывают сами, когда задача совпала с описанием.

## Обновиться до свежей версии

Проще всего — кнопка **«Починить движок»** в виджете: она делает всё сама.

Руками то же самое:
```
cd ~/hr-tech-design && git pull && ./scripts/link-knowledge.sh
```
Вторая команда обязательна: `git pull` приносит файлы, но новые скилы и команды подключает
именно она (Claude Code читает только `~/.claude`).

Затем переоткрой плагин в Figma — он подхватит новый код виджета. Версия видна на бейдже в углу.
