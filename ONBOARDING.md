# Булочка 4.28 · установка для дизайнера

Булочка даёт твоему помощнику знания HR Tech и доступ к открытому Figma-файлу. Помощник — тот,
которым ты уже пользуешься: **Codex** или **Claude Code**. Задачи ты по-прежнему ставишь обычными
словами. Там же остаются история, прогресс, остановка, лимиты и настройки модели.

У каждого дизайнера свой аккаунт помощника и локальный мост на его Mac. Подключаться к компьютеру
или серверу автора Булочки не нужно.

## Установка

В плагине открой **Настройки → Настроить подключение**. Кнопка скопирует команду:

```bash
curl -fsSL https://raw.githubusercontent.com/artsaverin-star/hr-tech-design/main/install.sh | bash
```

Открой Терминал, вставь команду и нажми Enter. Она настроит найденные Codex и Claude Code, мост и умения HR Tech. Отдельное приложение, Git, Homebrew и ручная установка Node не нужны.

После завершения открой новый чат помощника. В Claude используй вкладку **Code**. Оставь плагин открытым в рабочем файле Figma и попроси: «Подключись к Figma через Булочку и назови файл. Ничего не меняй».

Настройка сохраняется в `~/Library/Application Support/Bulochka`. Для восстановления можно повторить ту же команду. Токен Figma для чтения и изменения макетов не нужен.

## Как работать каждый день

1. Открой нужный файл в desktop Figma и запусти **Plugins → From Yandex → Bulochka**.
2. На **Главной** посмотри примеры: каждый показывает, с чем поможет Булочка и как сформулировать запрос.
3. Выдели экран в Figma и напиши задачу в чате Codex или Claude Code — своими словами или по примеру.
4. При необходимости открой **Настройки**, чтобы проверить подключение.
5. Оставь Figma-файл и Булочку открытыми, пока помощник меняет макет.

Примеры:

- «Переведи выделенный экран на mobile 375 по HRDS» — `hrtech-mobile`;
- «Проверь выделенный макет на HRDS и исправь нарушения» — `hrtech-audit`;
- «Собери эти экраны в спецификацию сценария» — `hrtech-spec`;
- «Заведи из этой спеки живой прототип в Прототипнице» — `hrtech-prototipnitsa`;
- «Синхронизируй живой прототип обратно в Figma-спеку» — `hrtech-proto-spec`.
- «Проверь в Аркадии, какие тексты и состояния уже реализованы» — `hrtech-arcadia`.

Помощник сам подберёт умение по смыслу. При необходимости его можно назвать явно, по имени.
Булочка не дублирует модель, настройки, разрешения, прогресс и остановку — всё это уже есть
у помощника.

## Что находится в Булочке

Под навигацией на обоих экранах всегда видна строка подключения: подключено, подключается,
нет подключения, пауза или несовпадение версий. Она позволяет проверить связь, не открывая Настройки.

### Главная

Короткое описание и минимальный список из шести примеров запросов. У каждого — одна строка о
результате: мобильный экран, проверка HRDS, спека сценария, живой прототип, обратная синхронизация
спеки или проверка реализации в Аркадии. Выбери пример и отправь задачу в чат помощника.

### Настройки

Здесь находятся:

- состояние подключения, текущий файл и помощь при сбое;
- версия Булочки, найденные помощники и количество умений HR Tech;
- необязательный личный Figma-токен;
- «Настроить подключение», «Обновить и восстановить связь» и «Скопировать отчёт»;
- подробности подключения для диагностики.

Сведения о помощниках и установленных умениях появляются, когда есть связь с локальным мостом.
Первая настройка: скопировать команду из плагина → выполнить в Терминале → открыть новый чат помощника.

## Figma-токен — комментарии и библиотека (по желанию)

Токен нужен для дополнительных операций через Figma API: комментариев, поиска по опубликованным
библиотекам и экспорта изображений через REST. Для основной работы с открытым макетом он не нужен.

1. Открой figma.com → аватар → **Settings → Security → Personal access tokens**.
2. Создай токен со скоупами: *File content* — Read; *Comments* — Write; *File metadata*,
   *File versions* — Read; *Library assets*, *Team library content* — Read.
3. В **Настройках** раскрой блок Figma-токена и вставь его.

Файл токена хранится на твоём Mac в `~/.hrtech/figma-token` с правами 600. Мост использует его для
запросов к Figma API; установщик также передаёт его в конфигурацию MCP помощника.

## Если что-то не так

1. Если команда не закончила настройку, ошибка указана в Терминале, а отчёт сохранён в `~/.hrtech/install.log`. Повторите ту же команду: она восстановит незавершённую установку.
2. Оставьте плагин открытым в нужном файле Figma. После первой настройки откройте новый чат помощника и попросите назвать файл через Булочку. В Claude используйте вкладку **Code**.
3. Если связи нет, нажмите **Настройки → Скопировать отчёт** и передайте его вместе с ошибкой из чата помощника.

Если плагина нет в **From Yandex**, проверьте рабочий аккаунт Figma и доступ к плагинам команды.

## Обновление и восстановление

Нажми **«Обновить и восстановить связь»** в настройках плагина. Мост скачает и проверит обновление, завершит текущую команду и подхватит новую версию. Перезапуск помощника не требуется.

Если мост недоступен, кнопка **«Настроить подключение»** скопирует ту же команду Терминала. Повторное выполнение восстановит пакет и настройки, сохранив личные заметки и токен.

Первый переход с версии 4.27 и старше требует один раз открыть новый чат помощника после выполнения команды: старые процессы ещё не умеют подхватывать обновление. Перезагрузка Mac не нужна.

## Как поделиться знанием

Командные правила и умения ездят через git, но выполнение остаётся личным. Проверенный приём можно
добавить в `claude/knowledge/team-notes.md` в формате `## Имя — дата`, затем отправить изменение в
репозиторий. После выпуска нового локального пакета остальные дизайнеры смогут установить новую версию умений.
