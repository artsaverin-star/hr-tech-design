# Булочка 5.0 · HR TECH DESIGN

Булочка — локальный мост между Figma и ИИ-помощником дизайнера плюс база знаний HR Tech (HRDS, паттерны, прод, поиск по Figma). Поддерживаются **Codex, Claude Code, Antigravity и Cursor**: все используют один MCP-сервер `figma-hrtech` и одни и те же умения. Задачи ставятся обычными словами в вашем помощнике — там же остаются аккаунт, история, лимиты и настройки модели.

Интерфейс выполнен в спокойной тёмной теме с пиксельной Булочкой и состоит из двух экранов:

- **Главная** — строка подключения, короткое описание и кликабельные примеры запросов (клик сразу копирует промпт в буфер).
- **Настройки** — карточка статуса и активного файла, переключатель **«Только этот файл»** (закрепление), обновление/восстановление, копирование команды установки, необязательный токен Figma и диагностика с журналом.

## Умения HR Tech

- **`hrtech-figma-search`** — поиск файлов, страниц, экранов и текстов по локальному каталогу Figma HR Tech;
- **`hrtech-mobile`** — desktop → mobile 375 по компонентам и правилам HRDS;
- **`hrtech-audit`** — аудит и исправление макета на соответствие HRDS;
- **`hrtech-spec`** — сборка и проверка спецификации сценариев;
- **`hrtech-prototipnitsa`** — Figma-спека → живой прототип в Прототипнице;
- **`hrtech-proto-spec`** — живой прототип → синхронизированная Figma-спека;
- **`hrtech-arcadia`** — продуктовый код и тексты как источник правды;
- **`hrtech-yteam`** — продуктовый контекст Яндекс Тима.

## Установка (через Терминал)

Вставьте одну команду в Терминал и нажмите Enter (отдельное приложение, Git, Homebrew, sudo и ручная установка Node не нужны; требуется macOS 13.5+):

```bash
curl -fsSL https://raw.githubusercontent.com/artsaverin-star/hr-tech-design/main/install.sh | bash
```

Команда скачивает и проверяет пакет по SHA-256, ставит собственный Node в `~/Library/Application Support/Bulochka`, прописывает MCP `figma-hrtech` и подключает умения для всех найденных на Mac помощников (Codex, Claude Code, Antigravity, Cursor).

После установки:
1. Откройте новый чат в вашем помощнике (в Claude Desktop — вкладка **Code**).
2. Откройте рабочий файл в Figma и запустите **Plugins → From Yandex → Bulochka**.
3. Напишите в чате: «Подключись к Figma через Булочку и назови файл. Ничего не меняй».

## Обновление и восстановление

- При подключённом мосте нажмите **«Обновить»** (или **«Починить»**) в **Настройках** — пакет обновится без перезапуска помощника, а активное MCP-соединение и закрепление файла сохранятся.
- При обрыве или переносе на новый Mac достаточно повторить ту же команду в Терминале — личные заметки (`team-notes.md`) и токен Figma сохранятся.
- Если файл открыт в нескольких вкладках Figma, кнопка **«Подключить здесь»** мгновенно переключит мост на текущее окно, а переключатель **«Только этот файл»** защитит задачу от случайного переключения вкладки.

## Для разработчиков

- Единый источник версии — `bulochka.version.json`.
- Исходники UI плагина лежат модульно в `src/plugin-ui/` и собираются в `figma-desktop-bridge/ui.html`.
- Полная сборка и проверка: `npm run build:all && npm test`.

Подробнее для дизайнеров — в `ONBOARDING.md`, для разработчиков — в `CLAUDE.md`, вклад в HRDS — в `HRDS-CONTRIBUTION.md`.
